# Portfolio Profesional - Joseph Alfonso

## Descripción del Proyecto

[cite_start]Este es mi sitio web de portafolio personal, diseñado para presentar mi perfil como desarrollador y mostrar mis proyectos destacados[cite: 6]. La funcionalidad principal del sitio es servir como una carta de presentación interactiva y responsiva, permitiendo a los reclutadores y colaboradores conocer mi stack tecnológico, revisar mis trabajos previos y contactarme directamente a través de redes sociales integradas.

## Tecnologías y Técnicas Utilizadas

El proyecto ha sido construido aplicando estándares modernos de desarrollo web:

- **HTML5**: Uso de etiquetas semánticas para mejorar el SEO y la accesibilidad.
- **CSS3**: Implementación de layouts complejos mediante **Flexbox** y **CSS Grid**.
- **Metodología BEM**: Organización de estilos mediante el patrón _Block, Element, Modifier_ para asegurar un código escalable y fácil de mantener.
- **Diseño Responsivo**: Uso de **Media Queries** para garantizar que la interfaz sea funcional y estética tanto en dispositivos móviles como en escritorio.
- **Efectos Visuales**: Creación de profundidades y efectos de iluminación mediante gradientes radiales y filtros de desenfoque (`blur`).
- **Git & GitHub**: Control de versiones y despliegue continuo.
