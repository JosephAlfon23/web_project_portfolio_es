## Detalles Técnicos (Código)

El proyecto utiliza una arquitectura de estilos moderna y optimizada:

### HTML

- **Metodología BEM**: El código está organizado con clases claras (ej. `features__card`, `header__title`) para facilitar el mantenimiento.
- **Accesibilidad**: Uso de etiquetas semánticas y atributos `alt` en imágenes.

### CSS (Estilos)

- [cite_start]**Variables (Root)**: Uso de `--bg-dark`, `--color-white` y gradientes radiales para una consistencia visual[cite: 6].
- [cite_start]**Responsividad**: Implementación de Media Queries para adaptar el diseño a dispositivos móviles (max-width: 600px y 768px), ajustando el grid de 2 columnas a 1 sola para mejorar la legibilidad[cite: 6].
- **Efectos Visuales**: Uso de pseudo-elementos (`::before`, `::after`) con filtros `blur` para crear efectos de iluminación de fondo.
